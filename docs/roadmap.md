# 开发路线

## 1. 需求与基础学习

- [ ] 确定应用场景和两端口电气指标。
- [ ] 整理双向变换、功率器件、采样和反馈控制笔记。

## 2. 方案与仿真

- [ ] 根据电压关系、隔离和功率要求比较拓扑。
- [ ] 记录功率级、驱动、采样和控制器选型依据。
- [ ] 建立功率级模型并验证两个能量传输方向。
- [ ] 建立控制模型，记录稳定性和动态响应分析。

## 3. 硬件设计

- [ ] 完成原理图、BOM 和设计计算。
- [ ] 完成 PCB 布局布线与设计检查。
- [ ] 明确测试点、调试接口和硬件保护路径。

## 4. 固件开发

- [ ] 建立控制器工程与可复现的构建说明。
- [ ] 实现采样校准、PWM、状态管理和故障处理。
- [ ] 实现选定控制算法与方向切换逻辑。

## 5. 调试与验证

- [ ] 制定上电、功能和故障验证计划。
- [ ] 记录两个方向的电压、电流、波形、效率及温升。
- [ ] 对照需求记录通过项、偏差和修订。

## 6. 整理与发布

- [ ] 补齐工具版本、构建步骤、硬件版本及已知问题。
- [ ] 整理设计文件、测试结果和开发总结。
- [ ] 决定是否采用开源许可证。
